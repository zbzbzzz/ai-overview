# 资讯按内容合并为资讯束

不再仅用标题/URL 字符串去重。同一事件的多源报道先粗筛再由 Grok Bot 确认，合并为一条资讯束：保留一个主标题，下列全部外链。不同事件的深度文不硬并。

主标题优先官方源，否则取束内最清晰一篇；分点综合束内摘要 2–4 条；先合并为资讯束再打资讯重要度，Top10/重点按束计。主链可点，其余收入「另 N 篇报道」。合并失败时退回标题/URL 去重，页脚标注「合并降级」。

护栏（`generate.py` 的 `load_news_bundles`）：非主链外链必须带 `same_event: true`（模型逐条确认同一事件）才留在束内，否则自动拆成独立单条资讯束；一个 URL 只属于一个资讯束（已是别的束主链的不再重复挂）。关键词只能用于粗筛候选，不能直接决定合并。
