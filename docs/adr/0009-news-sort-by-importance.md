# 本周 AI 资讯按资讯重要度排序

原先按日期新→旧排列资讯。现改为：对 WayToAGI 近 7 天条目由本站打「资讯重要度」（行业冲击优先，再可动手价值），降序展示；重要度相近时用平局日期序。不改用 daily-brief 的现成 importance_score 作为唯一来源，以免丢掉当前周窗信源。

## Scoring (accepted)

每小时更新时用模型对 WayToAGI 近 7 天条目打资讯重要度（不退回纯规则）。权重：行业冲击 50%、可动手价值 35%、覆盖面 15%。同分用平局日期序。页面仅前 3 条显示「重点」标签，不展示原始分数。

## Model & display (accepted)

资讯重要度由 Grok Bot 运行时模型打分（不是仓库 DEEPSEEK_API_KEY）。展示固定 Top 10；前 3 条标「重点」。模型不可用时退回规则分并页脚注明「重要度降级」。
