- **最新页**：[zbzbzzz.github.io/github-trending](https://zbzbzzz.github.io/github-trending/)（始终等于当天日快照）
- **往期速览**：[history.html](./history.html)（按月浏览）
- **月归档**：`archive/YYYY-MM/`
