  2. Google 发布 Gemini 4 Neon：主打快速端到端任务，AA 智能指数 61 分列第三，API 定价 $3/$15
    Google 官方博客 · X：Artificial Analysis (@ArtificialAnlys) · X：Rohan Paul (@rohanpaul_ai) · 另 16 篇报道 · 最新 11-19 05:45
    • Google 发布 Gemini 4 Neon，定位在复杂软件工程、知识工作和科学工作流中以前沿智能快速完成端到端任务：支持多文件调试与重构、100 万 token 上下文和 4 档可调思考级别，官方称其在内部 Antigravity 测试中幻觉率为迄今最低。

    • 即日起向 Google AI Pro/Ultra 订阅用户在 Gemini 应用的 Chat 与 Tasks 中开放，并登陆 Gemini API 付费层（gemini-4-neon，每百万 token 输入 $3 / 输出 $15）、AI Studio、Antigravity 与 Gemini 商业版；官方称写作更利落，对表格、PDF 和照片等上传文件的解析也更准。
