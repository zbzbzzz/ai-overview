  2. OpenAI 与 Cisco 开源 Linux 运行时 Shirudo：用 eBPF shield 在补丁窗口期保护运行中的系统 重点
    OpenAI：官网动态（RSS · 排除企业/客户案例） · X：Tibo (@thsottiaux) · IT之家·人工智能 · 另 6 篇报道 · 最新 11-25 17:41
    • OpenAI 与 Cisco 发布开源 Linux 运行时 Shirudo（日语“盾”），用 eBPF 生成可密码签名验证的临时 shield，在不重启服务的情况下拦截漏洞利用，为测试和部署正式补丁争取时间；协议为 BSD 2-Clause，BPF 程序采用 BSD 与 GPL 双许可。
    • 受控测试中，用 Codex 生成的 shield 为运行中的 Elasticsearch 的 Java Base64 解码器加入输入检查，成功拦下 Java4Shell 攻击。系统还支持加载前校验、TPM 硬件证明，并设计让安全团队与 Agent 协作定位受影响系统、验证并部署 shield。
    • OpenAI 总裁 Greg Brockman 随后表示，团队正在编写 Shirudo Shields 以防御新出现的 CVE。
